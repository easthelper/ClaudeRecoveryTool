# Claude 실행 복구 도구

Windows에서 Claude 업데이트 후 **“이 파일을 다른 응용 프로그램에서 사용 중입니다”** 오류가 날 때, 이전 버전의 실행 컨테이너에 남은 프로세스를 조회하고 선택·일괄 종료하는 개인용 도구.

## 실행

1. `ClaudeRecoveryTool.exe`를 더블클릭.
2. Windows 관리자 권한 확인 창에서 승인. 구버전 컨테이너 소속을 정확히 조회하기 위해 필요한 권한이며, 실행 직후에는 조회만 수행.
3. 목록에서 프로그램 이름, PID, 시작 시각, 소속 버전 확인. 행을 클릭하면 아래에 전체 경로와 명령줄 표시.
4. 필요한 항목을 체크하고 **선택 항목 종료**, 또는 **구버전 일괄 종료** 클릭.
5. 종료 대상 목록을 확인하고 **위 항목 종료** 클릭. 취소 또는 Enter의 기본 동작은 취소.
6. 자동 재검사 결과 확인 후 **Claude 실행** 클릭.

설치·Python·PowerShell 7·별도 패키지 다운로드 불필요. Windows 10/11 x64, .NET Framework 4.8 이상 필요. 제작 PC의 .NET Framework 4.8.1에서 확인.

UAC는 Claude를 사용하는 Windows 계정으로 승인. 다른 관리자 계정의 자격 증명으로 실행하면 그 계정의 설치 정보와 컨테이너가 기준이 되므로, 원래 계정의 문제를 찾지 못할 수 있음.

## 화면과 종료 범위

| 기능 | 동작 |
|---|---|
| 다시 검사 | 현재 설치된 Claude 버전, 컨테이너, 실제 소속 프로세스를 새로 조회 |
| 선택 항목 종료 | 화면에 표시한 후 사용자가 체크·승인한 프로세스만 직접 종료 |
| 구버전 일괄 종료 | 검사 시점에 정리 가능한 것으로 표시된 구버전 프로세스를 한 번에 승인·종료 |
| 보호 항목 표시 | 현재 버전, 서비스 등 종료할 수 없는 대상도 표시 |
| 진단 저장 | 버전·소속·프로세스 정보가 담긴 JSON 저장. 명령줄 원문은 제외 |
| Claude 실행 | Windows 탐색기를 통해 앱 실행 요청. 앱 창이 실제 열리는지는 별도 확인 |

원격 연결, 개발 서버, 로그 감시 창도 구버전 Claude에 속할 수 있음. 종료 시 해당 작업이 중단되며, 콘솔 종료로 연결된 자식 프로세스가 함께 종료될 수도 있음. 이 도구는 종료한 서버나 원격 요청을 자동으로 복원하지 않음.

검사 중 새로 생긴 프로세스는 일괄 종료에 자동 편입하지 않음. 정리 후 남은 후보를 확인하고 필요한 경우 다시 선택.

## 보호 기준

- 정확한 Claude 패키지 식별자와 현재 설치 버전을 조회한 뒤, **설치 버전보다 오래된 사용자 컨테이너**만 정리 후보로 분류.
- 현재 버전, 설치 버전보다 새 버전, 다른 사용자, 다른 로그인 세션, 패키지 서비스, 중요 시스템 프로세스, 도구 자체는 보호.
- 접근 거부나 조회 실패는 `검사 일부 실패`로 표시. 이를 `문제 없음`으로 처리하지 않음.
- 구버전 컨테이너가 남았지만 소속 프로세스가 0개이면 미해결 상태로 표시. 커널 핸들을 강제로 닫거나 서비스 전체를 종료하지 않음.
- 종료 직전에 설치 상태, 실제 컨테이너 소속, 실행 경로, 시작 시각을 재검증. 같은 열린 프로세스 핸들로 검증과 종료를 수행해 PID 재사용에 따른 오종료 차단.
- 검사 후 버전 변경이 감지되면 다시 검사를 요구하거나 이후 일괄 종료를 중단.
- 파일·대화·설정 삭제, 앱 재설치, 레지스트리·서비스 설정 변경, 예약 작업 등록 기능 없음.

종료는 Windows의 `TerminateProcess`를 사용한 강제 종료. 저장되지 않은 작업을 정상 저장하는 절차가 아니므로, 확인 화면에서 대상을 검토하고 진행.

## 결과 기록

종료 대상과 결과는 `%LOCALAPPDATA%\ClaudeRecoveryTool\Logs` 아래에 JSONL로 저장. 기록 작성에 실패하면 종료를 시작하지 않음. 명령줄 원문은 로그에도 저장하지 않음. 외부 전송 기능 없음.

명령줄에서 읽기 전용 진단도 가능:

```powershell
# 관리자 PowerShell에서 실행
.\ClaudeRecoveryTool.exe --scan-json C:\Temp\claude-diagnostic.json
```

종료 코드: `0` 검사 완료, `2` 일부 조회 실패, `3` 실행/저장 실패. 저장 폴더는 먼저 생성. 프로세스를 종료하는 CLI 옵션은 제공하지 않음.

## 적용 범위와 한계

2026-09-26에 실제 PC에서 확인한 **업데이트 뒤 구버전 AppX 컨테이너 잔존** 문제를 대상으로 제작. 모든 Claude 실행 오류를 해결하는 범용 복구 도구는 아님.

현재 버전 컨테이너만 남은 경우에는 자동 정리하지 않음. 프로세스가 없어도 컨테이너를 유지시키는 커널 핸들 문제가 있거나, 설치 등록이 손상된 경우 추가 진단 필요. Windows 내부 객체 이름이 변경되면 검색 방식 수정이 필요할 수 있음.

## 소스와 빌드

`source` 폴더에 C# 소스, 테스트, 빌드 스크립트 포함. Windows 기본 .NET Framework 컴파일러를 사용하며 NuGet 의존성 없음.

```powershell
powershell -NoProfile -File .\source\Build.ps1
```

검증용 실행 파일까지 빌드하려면 별도 작업 폴더 지정:

```powershell
powershell -NoProfile -File .\source\Build.ps1 -OutputDirectory .\test-build -Tests
.\test-build\ClaudeRecoveryTests.exe .\test-results
```

테스트는 자신이 생성한 테스트용 프로세스만 종료. 실제 Claude는 읽기 전용으로만 조회. 화면 예제의 PID·경로·버전은 합성 데이터.

기술 근거: [Windows Job Objects](https://learn.microsoft.com/en-us/windows/win32/procthread/job-objects), [IsProcessInJob](https://learn.microsoft.com/en-us/windows/win32/api/jobapi/nf-jobapi-isprocessinjob), [동일 증상 보고](https://github.com/anthropics/claude-code/issues/73107).
